# Amelia Hub (MVP)

This plugin adds a central front-end hub via shortcode:

- Shortcode: `[amelia_hub]`
- Student flight-history lookup (email/phone)
- Fleet status snapshot from `wp_aircraft`
- Role-based quick sections for Student / CFI / Admin
